## 内容

**育翔小学一年级寒假作业**

+----------+-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| **\      | 同学们，快乐的寒假生活即将开始。我们在休息之余，也要注意语文基础知识的复习巩固，为新学期的学习做好准备。请大家认真完成寒假作业。                                                                                                                                      |

|          | 一、我是小小书法家                                                                                                                                                                                                                                                    |

|          | 抄写书上118页"写字表"中的生字**。**（写在自己准备的练习本上。每字两遍，写两个字空一格。要求书写正确、规范、整洁。）                                                                                                                                                   |
|          |                                                                                                                                                                                                                                                                       |
|          | 二、新年目标我制定                                                                                                                                                                                                                                                    |
|          |                                                                                                                                                                                                                                                                       |
|          | 新学期你有什么目标？请你用A4纸做一个目标卡，把你在学习或生活上的一、两个目标工整地写下来（不会的字可以写拼音）。开学后同学们将一起进行交流。                                                                                                                          |

| **数学** | 亲爱的同学们，愉快的寒假到来了，你做好假期的安排了吗？相信你是一个时间的小主人，能将自己一天的学习生活安排的井井有条。我们已经在本学期认识了钟表，了解了一些关于时间的内容。请你结合学过的知识，完成下面的实践活动。                                                  |

|          |                                                                                                                                                                                                                                                                       |

|          | **活动二：制作一个小钟表**                                                                                                                                                                                                                                            |
|          |                                                                                                                                                                                                                                                                       |
|          | **活动内容：**请你设计并制作一个属于自己的钟表。根据自己制定的一日作息时间表，设置"小闹钟"。边拨钟表边向家人介绍：现在是什么时间，我应该做什么事情了。                                                                                                                |
