# 4F回顾法复盘模板

---

**「动态回顾循环」Active ReviewingCycle**
这是英国学者Roger Greenaway提出的引导技巧，“动态引导反思法”，也称“4F回顾法”归纳出四个「F」的提问重点，即：

Facts(事实)
Feelings（感受、体会）
Findings（发现）
Future use（未来的运用）

|     |     |
| --- | --- |
| **2020年年末总结-4F回顾模型** |     |
| ****Facts****<br>****（事实）**** | _\[__填写指引\]__就是摆事实，讲道理，完全复述事情的真实情况；它表示在体验中实际做的、看到的、听到的。帮助自己回忆过程中发生了什么，主要带着一个不评判的角度来回忆。_<br><br> |
| ****Feelings****<br>****（感受、体会）**** | _主要针对第1点Facts对某一事件发生后内心的主观感受、体会、感想或直觉。人的行为往往是受情感支配着的，所以在动态回顾的第二个环节，会回顾在facts的背后情感是什么。同时通过对感受的了解，来判断这个行为/事实达到了什么效果。_<br><br> |
| **Findings**<br>**（发现、原因）** | _通过客观存在的事实，分析事实背后的情感，然后发现、寻找产生情感或导致的行为的原因，从而总结哪些经验带来了改变（意义、认知），解决问题。_<br><br> |
| **Future use**<br>**（运用）** | _通过上述的事实、感受、发现，将所学的用在现实生活中。以后遇到同样的或者类似的情况我们要怎么做。_<br><br> |
