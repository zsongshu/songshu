# 关于点招



|     |     |
| --- | --- |
| 途径  | 官宣的：**人大附（早培）、十一集团校、八中（八少八素）、各城区特色校、特长生等**<br>**半公开：****西城德胜中学、丰台十二中、朝阳八十中王选等** |
| 要求  | 1. 语数英<br>	1. 语文至少要有初中水准，尤其是古诗词、作文和阅读理解<br>	2. 数学，主要看奥数，需要参与一些比赛来获得相应等级的证书<br>	3. 参加剑桥英语等级考试（简写MSE），最好有PET或以上等级，现在小学就有FCE的孩子越来越多<br>2. 个人简历<br>3. 奥赛、三好等 |
| **八少八素** | 八中少年班：一般招收10岁左右的孩子（四五年级），五年内完成高中课程，14-16岁高考<br>八中素质班：面向四年级孩子，4+3模式，4年学完5~9年级课程，3年是正常高中 |
| 其他信息 | 校内考试成绩和老师评价，尤其是五下六上时期，个别学校就看五下六上成绩表现（德胜中学）<br>各种竞赛提前准备起来 |
