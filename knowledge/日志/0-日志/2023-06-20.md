# 2023-06-20

Reader文件上传逻辑，涉及3个Thread（写入线程、上传线程、清理线程、压缩线程）

|     |     |
| --- | --- |
| 写入线程 | 负责写入数据文件（L1、L2、MaxBinlog、Data），在Data文件切换时刻更新L2，并将L1、L2、MaxBinlog文件复制到upload目录（使用版本号标识3个文件属于一个snapshot，并把文件名持久化到upload文件中） |
| 上传线程 | 读取upload文件，获取同一个版本的数据文件并上传到S3（若文件未压缩则同步执行压缩），完成S3动作后删除索引文件 |
| 清理线程 | 负责定时清理数据文件 |
| 压缩文件 | 压缩upload文件夹中的文件 |
