# 微调

微调技术统一称为 **PEFT**（Parameter-Efficient Fine-Tuning，参数高效微调）。由于现在的模型太大（动辄千亿参数），全量微调（Full Fine-Tuning）太贵且太慢，所以催生了各种“只动一小部分参数”的黑科技。除了 LoRA 之外，微调技术主要分为以下四大流派：

---

### 1\. 增加式流派 (Additive Methods)

这类技术不改变原模型，而是在旁边或者里面“加外挂”。

* **Adapters (适配器微调)**：
	* **逻辑**：在 Transformer 的层与层之间插入小型网络层（Bottleneck 结构）。训练时只更新这些小层。
	* **缺点**：因为增加了额外的层，推理时会带来额外的延迟（Latency）。
* **Prompt Tuning (提示词微调)**：
	* **逻辑**：不改模型，也不改输入文字，而是在输入层前面拼上一段“虚拟 Token”（一串可学习的向量）。
	* **比喻**：给模型戴了一个“助听器”，让它专门听某种特定频段的声音。
* **Prefix Tuning (前缀微调)**：
	* **逻辑**：比 Prompt Tuning 更深，它在模型的**每一层**都加上一段可学习的前缀向量。

---

### 2\. 重参数化流派 (Reparameterization-based)

这就是 **LoRA** 所在的流派。

* **LoRA (Low-Rank Adaptation)**：
	* **逻辑**：利用低秩矩阵（A 和 B）来模拟参数的变化量。
	* **优势**：推理时可以把 A×B 直接加回原权重，**实现零延迟推理**。
* **QLoRA**：
	* **逻辑**：LoRA 的进化版。先把原模型量化成 4-bit（极度压缩），再挂载 LoRA。这让你能用一张普通的家用显卡（如 3090/4090）微调一个巨大的 70B 模型。

---

### 3\. 选择性流派 (Selective Methods)

不增加新参数，只从原模型里挑一小部分“幸运儿”进行训练。

* **BitFit**：
	* **逻辑**：极其极端。它**只微调模型里的 Bias（偏置项）**。
	* **神奇之处**：偏置项通常只占总参数的 0.1% 不到，但在某些任务上效果出奇地好。非常适合算力极其有限的场景。
* **Diff Pruning**：
	* **逻辑**：学习一个稀疏的更新矩阵，只修改那些对任务最关键的权重。

---

### 4\. 混合流派 (Hybrids)

* **UniPELT**：
	* **逻辑**：小孩子才做选择，大人全都要。它把 LoRA、Prefix Tuning 和 Adapters 组合在一起，通过一个门控机制自动决定哪种技术最适合当前任务。

---

### 🏛️ 架构师视角的选型指南

如果你在阿里巴巴构建 AI 应用底座，可以参考这个决策矩阵：

|     |     |     |     |
| --- | --- | --- | --- |
| **技术** | **训练成本** | **推理延迟** | **适用场景** |
| **Full Fine-Tuning** | 极高  | 无   | 需要模型学习完全不同的新领域知识（如从零学法律）。 |
| **LoRA / QLoRA** | **极低** | **无** | **工业界标准。** 锁定画风、特定人物、特定代码风格。 |
| **Prompt Tuning** | 极低  | 微弱  | 只要模型做简单的分类、情感分析，不想动模型架构。 |
| **Adapters** | 低   | 较高  | 适合多任务并存，但对 RT（响应时间）不敏感的后台任务。 |
