# SOP-写技术方案

#  

1. 现状与痛点 (Why We Do It)
	1. 从现状引入痛点，回答为什么要做
	2. 不仅要说明问题，还要引起共鸣，确立项目的必要性
2. 目标与范围 (What We Achieve)
	1. 定义目标，明确范围，回答要做成什么样子
	2. 明确项目的边界和成功的标准
3. 架构设计与核心思路 (How We Approach)：
	1. 回答打算怎么做
	2. 阐述总体的技术选型和设计原则
	3. 清晰的架构图：展示核心组件及其关系
	4. 核心技术选型和理由
	5. 关键设计原则
4. 核心功能模块 (What We Build)
	1. 突出重点，回答具体怎么做
	2. 按模块分解
5. 实施路径与计划 (When We Deliver)
	1. 将宏大的目标分解为可执行的步骤
