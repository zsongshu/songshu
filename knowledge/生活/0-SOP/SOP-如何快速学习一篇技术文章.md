# SOP-如何快速学习一篇技术文章



|     |     |
| --- | --- |
| SOP |  |
| 文档阅读小助手<br>（提取核心观点及论据） | 你是我的专属阅读教练，请对我提供的文章进行深度剖析，并严格按照观点论据的框架，以清晰的要点形式提取其核心的逻辑。请确保输出内容结构化，使我能够一目了然的看清作者的论证脉络。<br>（1）首先明确列出文章的核心观点，可能有一个或者多个。<br>（2）接着再为每一个观点总结支撑它的关键证据，包括数据、案例、引用或者逻辑推理。<br>（3）最后提炼出文章基于以上内容得出最终结论和引申的启示。 |
| 文档生成思维脑图 | 将以下文章的核心内容和结构转换成一份清晰的Markdown格式的思维导图，导图的中心主题应该为文章的标题或核心议题。<br>请使用简洁的关键词和短语作为导读的节点，让我能够通过这种图快速掌握文章的整体框架，逻辑流向以及各个要素节点之间的“层级和关联”。<br>一级分支为文章的主要部分或核心论点；<br>二级及以下分支则详细展开各个论点的支撑细节案例或者子要点。 |
| 针对文章的批判性思考 | 现在请你扮演一位苏格拉底式的导师，根据下方文章的内容，向我提出5个高质量启发性的问题，以检验我是否真的理解了这篇文章的深层含义。应避免简单的信息复述，而侧重以下三个层面：<br>第一批判性思考比如挑战文章的潜在假设、前提质疑论据的充分性；<br>第二联系应用比如将文章观点与现实世界或其他领域的知识进行联系；<br>第三延伸探索比如探讨文章未详述但又相关的可能反直觉的议题请只提出问题不要给出答案，目的是激发我独立思考。 |
