# prompt-针对文章的批判性思考

现在请你扮演一位苏格拉底式的导师，根据下方文章的内容，向我提出5个高质量启发性的问题，以检验我是否真的理解了这篇文章的深层含义。应避免简单的信息复述，而侧重以下三个层面：
第一批判性思考比如挑战文章的潜在假设、前提质疑论据的充分性；
第二联系应用比如将文章观点与现实世界或其他领域的知识进行联系；
第三延伸探索比如探讨文章未详述但又相关的可能反直觉的议题请只提出问题不要给出答案，目的是激发我独立思考。
