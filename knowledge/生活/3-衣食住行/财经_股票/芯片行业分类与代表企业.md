# 芯片行业分类与代表企业



|     |     |     |     |     |
| --- | --- | --- | --- | --- |
| 芯片类型 | 主要特征 | 国际代表企业 | 国内代表企业 | 国内企业特点 |
| **计算型芯片** | 用于数据处理和计算，是电子设备的"大脑" | 英特尔、AMD、ARM、英伟达、高通 | 龙芯、飞腾、兆芯、华为鲲鹏、寒武纪 | 2025年AI芯片企业如寒武纪出货量年均增长率超120%，AI推理市场占有率突破30% |
| CPU | 通用计算核心，处理指令和数据 | 英特尔、AMD、ARM | 龙芯、飞腾、兆芯、华为鲲鹏 | 龙芯中科2025年三季度净亏损3.94亿元，但仍在持续研发中 |
| GPU | 用于图形渲染和并行计算，加速AI计算 | 英伟达、AMD、Intel | 景嘉微、沐曦 | 国内GPU企业正在加速追赶，但与国际领先水平仍有差距 |
| AI芯片 | 专门用于人工智能计算，加速深度学习 | 英伟达、谷歌TPU、AMD | 寒武纪、地平线、百度昆仑、华为昇腾 | 寒武纪2025年三季度营收46.07亿元，同比激增2386.38%；净利率达34.8% |
| **存储型芯片** | 用于数据存储，是电子设备的"记忆" | 三星、SK海力士、美光、东芝 | 长江存储、长鑫存储、兆易创新 | 中国存储芯片企业正在快速突破，长江存储已进入NAND Flash市场 |
| DRAM | 动态随机存取存储器，临时存储数据 | 三星、SK海力士、美光 | 长鑫存储 | 国内DRAM企业正在加速追赶，长鑫存储已实现技术突破 |
| NAND Flash | 闪存，用于长期数据存储 | 三星、东芝、美光 | 长江存储 | 长江存储已成为中国NAND Flash领域的领军企业 |
| NOR Flash | 用于嵌入式系统存储 | 三星、美光、西部数据 | 旺宏电子、兆易创新 | 兆易创新在NOR Flash领域有较强竞争力 |
| **通信型芯片** | 用于无线通信，实现数据传输 | 高通、联发科、博通 | 华为海思、紫光展锐、卓胜微 | 紫光展锐在5G手机领域表现突出，是国产5G手机中坚力量 |
| 基带芯片 | 处理通信信号，实现无线通信功能 | 高通、联发科、华为海思 | 华为海思、紫光展锐 | 华为海思的麒麟系列在高端手机SoC领域具有竞争力 |
| 射频芯片 | 处理射频信号，用于无线通信 | Qorvo、Skyworks、博通 | 卓胜微、慧智微、唯捷创芯 | 卓胜微是中国射频前端平台级龙头企业 |
| 通信协议芯片 | 实现通信协议，支持多种通信标准 | 高通、联发科 | 华为海思、紫光展锐 | 紫光展锐掌握从2G到5G的通信技术 |
| **模拟芯片** | 处理模拟信号，连接数字世界与物理世界 | 德州仪器、亚德诺、安森美 | 圣邦微、思瑞浦、纳芯微、芯海科技 | 国内模拟芯片企业正在加速突破，圣邦微是行业龙头 |
| 信号链模拟芯片 | 处理模拟信号，包括运放、ADC/DAC等 | 德州仪器、亚德诺 | 圣邦微、思瑞浦、纳芯微 | 圣邦微电子是"中国模拟IC芯片设计龙头"，思瑞浦在信号链模拟芯片领域表现突出 |
| 电源管理芯片 | 管理和分配电力，提高能源效率 | 德州仪器、安森美、英飞凌 | 圣邦微、芯朋微、芯洲科技 | 电源管理芯片是模拟芯片的重要细分领域 |
| 接口芯片 | 实现设备间通信接口 | 英飞凌、德州仪器 | 深圳华大北斗、芯海科技 | 国内企业正在加速开发高性能接口芯片 |
| **传感器芯片** | 捕捉物理世界信息并转换为电信号 | 索尼、豪威科技、STMicroelectronics | 格科微、思特威、韦尔股份 | 格科微在图像传感器市场强势崛起，韦尔股份在CMOS图像传感器领域领先 |
| 图像传感器 | 捕捉光线并转换为电信号 | 索尼、豪威科技、三星 | 格科微、思特威、韦尔股份 | 格科微在图像传感器市场强势崛起，2025年市场表现良好 |
| MEMS传感器 | 用于测量物理量，如加速度、压力 | STMicroelectronics、博通 | 无锡华润微、歌尔股份 | 国内MEMS传感器企业正在加速发展 |
| **专用芯片** | 针对特定应用领域设计 | 恩智浦、英飞凌、德州仪器 | 地平线、黑芝麻智能、比亚迪半导体 | 汽车电子芯片是当前重要增长点，国内企业正在加速布局 |
| 汽车电子芯片 | 用于汽车电子系统，如ADAS、车载信息娱乐 | 恩智浦、英飞凌、德州仪器 | 地平线、黑芝麻智能、芯驰科技 | 汽车电子是芯片行业重要增长点，国内企业正在加速布局 |
| 工业控制芯片 | 用于工业自动化和控制系统 | 德州仪器、意法半导体、英飞凌 | 中芯国际、兆易创新、芯海科技 | 工业控制芯片是国产替代的重要领域 |



## **国产已实现全方面替代的芯片类型**

|     |     |     |     |
| --- | --- | --- | --- |
| 芯片类型 | 国产替代情况 | 代表企业 | 优势领域 |
| **28nm及以上成熟制程芯片** | **已实现全方面替代** | 中芯国际、华虹半导体 | 汽车电子、工业控制、IoT、家电芯片等 |
| **模拟芯片** | **已实现全方面替代** | 圣邦微、思瑞浦、纳芯微 | 信号链、电源管理、接口芯片等 |
| **射频芯片** | **已实现全方面替代** | 卓胜微、慧智微、唯捷创芯 | 5G通信、物联网设备 |
| **NOR Flash存储芯片** | **已实现全方面替代** | 兆易创新 | 嵌入式系统、消费电子 |
| **车规级芯片** | **已实现部分替代** | 地平线、黑芝麻智能、芯驰科技 | 辅助驾驶、车载信息娱乐系统 |
| **基础AI芯片（推理）** | **已实现部分替代** | 华为昇腾、寒武纪、地平线 | 政务、金融、特定场景AI推理 |



## **仍有较大差距的芯片类型**

|     |     |     |     |
| --- | --- | --- | --- |
| 芯片类型 | 差距表现 | 代表企业 | 国际领先企业 |
| **7nm及以下先进制程芯片** | **差距约2-3年** | 中芯国际 | 台积电、三星、英特尔 |
| **高端CPU/GPU（训练芯片）** | **差距约3-5年** | 龙芯、飞腾、华为海思 | 英伟达、AMD、英特尔 |
| **AI训练芯片** | **差距约3-5年** | 寒武纪、华为昇腾 | 英伟达 |
| **EUV光刻机相关芯片** | **无法自主生产** | 无   | ASML |
| **高端EDA工具** | **仅覆盖28nm以上** | 华大九天、概伦电子 | Synopsys、Cadence、Siemens |
| **高端光刻胶** | **90%依赖进口** | 无   | JSR、东京应化 |
| **高端存储芯片（DRAM、NAND）** | **差距明显** | 长江存储、长鑫存储 | 三星、SK海力士、美光 |
| **RISC-V生态** | **尚处早期阶段** | 无   | ARM（市场占95%） |
