| **创新简化（Invent and Simplify）**：期望并要求自己的团队进行创新和发明，并始终寻求使工作简化的方法。了解外界动态，从各处寻找新的创意，并且不局限于“非我发明”的观念。 当开展新事物时，要接受被长期误解的可能。 |
| **决策正确（Are Right, A Lot）**：在大多数情况下都能做出正确的决定。拥有卓越的业务判断能力和敏锐的直觉，寻求多样的视角，并挑战自己的观念 |
| **选贤育能（Hire and Develop the Best）**：不断提升招聘和晋升员工的标准。表彰杰出的人才，并乐于在组织中通过轮岗磨砺他们。培养领导人才，严肃地对待自己育才树人的职责。从员工角度出发，创建职业发展机制。 |
| **远见卓识（Think big）**：局限性思考只能带来局限性的结果。大胆提出并阐明大局策略，由此激发良好的成果。从不同角度考虑问题，并广泛寻找服务客户的方式。 |
| **勤俭节约（Frugality）**：力争以更少的投入实现更大的产出。勤俭节约可以让我们开动脑筋、自给自足并不断创新。增加人力、预算以及固定支出并不会为你赢得额外加分。 |
| **刨根问底（Dive Deep）**：深入各个环节，随时掌控细节，并经常进行审核。当数据与传闻不一致时，持有怀疑态度，不会遗漏任何工作。 |
