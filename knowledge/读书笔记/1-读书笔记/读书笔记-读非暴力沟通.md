# 读书笔记-读非暴力沟通

非暴力沟通的力量，它的关注点并不是谁对谁错，也不是应该如何判断，而是通过对方的言语，来看清各自的需求和关心


1. 观察：学会区分观察与评论。观察的要素要求我们仔细观察正在发生的事情，然后客观而清晰地表达出我们所观察到的结果，而不是从我们自身的观念和角度出发进行评论。评论实际上就是我们自身把对他人的思想或者行为、愿望的推测当成一种唯一可能的结论，将一种预测或者评论当作事实，也就是说，评论往往言过其实；而观察则是对客观发生的事情，用语言描述出来，它的重心是“描述”。观察需要去分析结论产生的原因。
2. 感受：学会区分感受和想法。学会体会和表达自己的感受。感受是我们内心真实情绪的反应，也就是所谓的真情实感；而想法更多的是我们自身的一种感觉，一般都是“我觉得”“我感觉”如何。我们需要明确我们内心出现的种种感受及其背后的根源是什么，这将有助于我们更加深刻而真实地了解自己，同时也能够让我们更准确地将自我的感受通过语言表达出来。实际上，所有感受的背后，都是我们自身的愿望和期待，也正是这些愿望和期待，促使了众多情绪的产生。感受的背后是我们内心深处隐藏的期望和需要。所以，对于别人表达的感受，可以选择用全身心去倾听他，来表达出他没有说出来的感受，或背后隐藏着什么期望，然后将这些期望表达出来。
3. 需要：勇敢地说出我们的需要。了解自己和他人的需要，是健康的交流关系得以建立的重要因素。面对他人的情绪也是如此，我们需要先观察，全身心去倾听对方话语当中的情绪和感受，并通过及时的反馈加以确认，在此基础之上去感受和体会对方有哪些需求，同时寻求满足这些需求的方法。这就是非暴力沟通所强调的感受和需要。
4. 请求：学会区分请求与命令。(1)请求应当具体而清楚。（运用非暴力沟通的模式和方法，先观察，然后表达自己的感受和需要，再提出具体的请求，那么整个沟通就会变得更加顺畅。）(2)区分请求与命令（我们在表达自己的愿望和请求的同时，也要兼顾对方的需要，而不能忽视对方。）
5. 非暴力沟通，化解冲突的利器。1)充分体会和表达自己的感受和需要；(2)通过语言来感受对方的真实需要；(3)观察和分析自己与他人的需要是否已被真正地感受到；(4)倾听对方的请求；(5)将自我的观察转化为为具体的语言表达出来。
6. 非暴力沟通中的情绪管理技巧。(1)观察并控制情绪。(2)坦诚地表达。(3)即使在情绪无法控制的时候，也不要用指责和批判来表达。(4)注重倾听。非暴力沟通让我们意识到，任何一种情绪的背后都隐藏着没有被满足的需求。



* 克服公众演讲的恐惧：提前准备、想象听众是自己的某个挚友
* 对他人友善：批评和指责其实表明人们对他人有所期待
* 化解矛盾：1）表达我们的需求 2）感知他人的需求 3）确认自己是否听懂了别人的需求 4）用积极的语言提供解决方案
* 点燃团队：让员工充分表达想法；让他们倾听彼此的意见，理解他人的需求；最后尝试满足双方的需求
* 职场中化解矛盾：1）观察：矛盾出现先不要着急解决，先看一看各方的反应 2）反馈：将观察到的现象反馈给各方，告诉他们双方都做了什么 3）感受，将双方的行为给对方带来的感受告诉对方 4）提出请求，明确的告诉对方，希望他做些什么
* 消除人与人的隔阂：
	* 产生隔阂的原因：1）双方不愿意展示真实的自我 2）双方由于误会产生了隔阂 3）一方损害了另一方的利益
	* 如何解决：1）充分表达，真诚相处 2）善意理解，宽容大度 3）诚恳道歉
