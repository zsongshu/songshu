# 读书笔记-般若波罗蜜多心经

# 

观自在菩萨，行深般若波罗蜜多时，照见五蕴皆空，度一切苦厄。
舍利子！色不异空，空不异色；色即是空，空即是色。受想行识，亦复如是。
舍利子！是诸法空相，不生不灭，不垢不净，不增不减。
是故空中无色，无受想行识；无眼耳鼻舌身意；无色声香味触法；无眼界，乃至无意识界；
无无明，亦无无明尽；乃至无老死，亦无老死尽；无苦集灭道，无智亦无得。
以无所得故，菩提萨埵，依般若波罗蜜多故，心无挂碍；无挂碍故，无有恐怖，远离颠倒梦想，究竟涅槃。
三世诸佛，依般若波罗蜜多故，得阿耨多罗三藐三菩提。
故知般若波罗蜜多，是大神咒，是大明咒，是无上咒，是无等等咒，能除一切苦，真实不虚。
故说般若波罗蜜多咒，即说咒曰：揭谛揭谛，波罗揭谛，波罗僧揭谛，菩提萨婆诃。

| **舍利子，色不异空，空不异色，色即是空，空即是色，受想行识，亦复如是** | 菩萨对舍利子说：物质和空并无什么不同，两者本质是一体的。其他四韵与空的关系也是如此。 |
| **舍利子，是诸法空相，不生不灭，不垢不净，不增不减** | 一切有形无形的精神与物质-本相-空没有生死、没有脏净、不会增加也不会减少 |
| **是故空中无色，无受想行识，无眼耳鼻舌身意，无色声香味触法，无眼界，乃至无意识界** | 没有五蕴，没有六感官，也没有六感官所感知的对象，从认知感官的根器眼界到意识界的十八界都是空的 |
| **无无明，亦无无明尽，乃至无老死，亦无老死尽，无苦集灭道，无智亦无得** | 没有无知这种状态，也没有断除无知的尽头从无知到老死这一生命轮回都是不存在的也没有超越生死的老死尽没有四圣谛-不知苦、不断集、不修道、不证灭不存在般若智慧，也没有凭借智慧要得到的任何东西 |
| **以无所得故，菩提萨埵，依般若波罗蜜多故，心无挂碍，无挂碍故，无有恐怖，远离颠倒梦想，究竟涅槃** | 因为没什么可获得，所以菩萨依旧修行“般若波罗蜜多”心中没有牵挂和滞碍，由于没有挂碍，没有什么可害怕，远离一切不切实际的幻想，最终达到涅槃的境界 |
| **三世诸佛，依般若波罗蜜多故，得阿耨多罗三藐三菩提** | 过去、现在、未来的诸佛，所以凭借-般若波罗蜜多，获取-阿耨多罗（无上）三藐（正等）三菩提（正觉） |
| **故知般若波罗蜜多，是大神咒，是大明咒，是无上咒，是无等等咒，能除一切苦，真实不虚** | 由此可知，般若波罗蜜多-是神奇的咒语，是破除黑暗的光明咒语，是无与伦比的咒语，能消除一切苦难，并且是真实的 |
| **故说般若波罗蜜多咒，即说咒曰：揭谛，揭谛，波罗揭谛，波罗僧揭谛，菩提萨婆诃** | 所以说-般若波罗蜜多咒语，就是说：去吧，去吧，到彼岸去吧，大家都快去彼岸，修成正果 |
