# 一条 HTTP 请求的生命周期：淘宝商品详情页请求完整旅程详表



|     |     |     |     |     |
| --- | --- | --- | --- | --- |
| 系统层级 | 系统名称/组件 | 地理位置/角色 | 处理事项详细说明 | 关键技术/输出 |
| **第一站：**<br><br>**用户端** | **浏览器/App** | 用户设备 | 1\. [[DNS解析\|DNS解析]]：解析 [item.taobao.com](http://item.taobao.com/)<br><br>2\. **发起HTTPS请求**：构建HTTP请求，携带Cookie（如用户登录令牌）、User-Agent等。<br><br>3\. **等待与渲染**：接收响应，解析HTML、CSS、JS，并渲染页面。 | HTTP/2, QUIC, Cookie, JWT |
| **第二站：**<br><br>**全球调度** | **阿里云全局加速** | 阿里全球边缘节点 | 1\. [[智能DNS\|智能DNS]]：根据用户IP返回离用户最近的接入点IP。<br><br>2\. [[HTTP-DNS\|HTTP-DNS]]：防止本地DNS劫持，App直接通过HTTP API获取最优IP。<br><br>3\. **Anycast**：对同一IP，全球多个接入点均可响应，通过BGP路由选择最近节点。 | 智能DNS, HTTP-DNS, Anycast BGP |
| **第三站：**<br><br>**边缘网络** | **DCDN/SCDN**<br><br>（动态/安全CDN） | 阿里边缘节点 | 1\. **静态资源缓存**：直接返回商品图片、描述文本等不变的静态内容。<br><br>2\. **动态请求路由**：将无法缓存的动态请求（如价格、库存）以最优路径回源到杭州中心。<br><br>3\. **安全清洗**：初步过滤恶意流量、CC攻击。 | 缓存技术, 全路径加速, 边缘安全 |
| **第四站：**<br><br>**接入网关** | **云盾/高防IP**<br><br>**Web应用防火墙** | 杭州数据中心入口 | 1\. **DDoS防护**：抵御大规模流量攻击。<br><br>2\. **应用层攻击防护**：检查SQL注入、XSS等Web攻击。<br><br>3\. **流量整形**：限流，防止系统被突发流量冲垮。 | DDoS防护, WAF规则引擎, 限流熔断 |
| **第五站：**<br><br>**流量网关** | **Tengine**<br><br>（阿里定制Nginx）<br><br>**LVS**<br><br>（硬件负载均衡） | 前端代理层 | 1\. **负载均衡**：将请求分发到后台上千台 **阿里云网关** 服务器。<br><br>2\. **SSL/TLS终结**：解密HTTPS请求，减轻后端压力。<br><br>3\. **协议转换**：处理HTTP/2、QUIC等现代协议。<br><br>说明：先四层后七层，基于性能、成本、业务灵活性权衡 | 负载均衡算法, SSL Offloading |
| **第六站：**<br><br>**应用网关** | **阿里云网关/微服务网关** | 业务路由层 | 1\. **服务路由**：根据URL路径（/item.htm）识别出应调用 **“商品详情页”** 服务。<br><br>2\. **认证鉴权**：校验Cookie或Token中的用户身份，判断是否有权访问。<br><br>3\. **参数校验**：检查商品ID等参数合法性。<br><br>4\. **服务发现**：从注册中心（如Nacos）查询“商品详情页”服务的健康实例列表。 | 服务发现, 认证鉴权, 动态路由 |
| **第七站：**<br><br>**业务应用** | **商品详情页服务**<br><br>（一个Java微服务） | 核心业务逻辑层 | 1\. **请求聚合**：并行调用多个依赖服务获取数据：<br><br>\- **商品基础服务**（标题、描述、图片）<br><br>\- **价格服务**（实时价格、优惠计算）<br><br>\- **库存服务**（实时库存）<br><br>\- **用户服务**（会员等级、优惠券）<br><br>\- **评价服务**（好评率、评论数）<br><br>2\. **数据组装**：将各服务返回的数据拼接成商品详情页所需的数据模型。<br><br>3\. **模板渲染**：可能由后端渲染（BigPipe）或直接输出JSON由前端渲染。 | HSF（RPC框架）, 异步调用, 聚合模式 |
| **第八站：**<br><br>**依赖服务** | **HSF服务集群**<br><br>（高速服务框架） | 下游微服务 | 1\. **处理业务逻辑**：如价格服务计算满减、折扣、会员价。<br><br>2\. **缓存查询**：优先从分布式缓存 **Tair** 中读取数据，如商品信息。<br><br>3\. **数据库查询**：缓存未命中，则查询数据库。例如：<br><br>\- **商品库**：查询 **MySQL**（分库分表）或 **OceanBase**。<br><br>\- **库存库**：查询专用库存数据库，可能涉及 **行级锁** 控制超卖。<br><br>4\. **异步任务**：发送消息到 **RocketMQ**，异步更新商品浏览量、生成浏览记录。 | Tair（缓存）, MySQL/OceanBase（数据库）, RocketMQ（消息队列） |
| **第九站：**<br><br>**数据平台** | **实时计算平台**<br><br>（如Blink） | 大数据层 | 1\. **实时指标计算**：消费RocketMQ中的浏览消息，实时计算商品热度、区域偏好等。<br><br>2\. **个性化推荐**：根据用户实时行为，更新推荐模型。 | 流计算, 实时数仓 |
| **第十站：**<br><br>**返回路径** | **反向路径** | 从数据源返回 | 1\. **数据逐级返回**：DB/Cache -> 依赖服务 -> 商品详情服务 -> 网关 -> ...<br><br>2\. **添加缓存**：将最终渲染的页面或数据片段在 **CDN** 或 **网关层** 缓存很短时间（如几秒钟），应对瞬时爆款。<br><br>3\. **响应输出**：将完整的HTML页面或JSON数据通过建立的连接通道返回给用户。 | 多级缓存, 动态内容缓存 |
| **终点站：**<br><br>**客户端** | **浏览器/App** | 用户设备 | 1\. **接收响应**：收到HTML或JSON数据。<br><br>2\. **二次请求**：解析HTML中的图片、CSS、JS链接，再次向CDN发起请求。<br><br>3\. **渲染页面**：最终将完整的商品详情页呈现给用户。 | 客户端渲染, 资源加载 |
