# 读书笔记-结构化思维

这份内容的核心是：提升逻辑思维，关键在于“读写结合”的刻意练习，并运用“批判性思维模型”作为分析工具。 它不是天赋，而是可训练的方法。以下是结构化总结，并整合了原文中的关键例子：

### 一、 核心理念：逻辑是练出来的，不是想出来的

逻辑能力的作用：增强说服力、避免被误导、形成独立见解。提升路径：“输入”（阅读）与“输出”（写作）相结合，这是AI无法替代的底层训练。

### 二、 两大基础训练方法

1. 通过“读硬书”训练结构化思维
	* 是什么：像制作公司PPT一样，将核心观点拆解为分论点、论据和数据的“大纲式”思维。AI总结的内容就是典型的结构化呈现。
	* 怎么做：主动阅读非虚构类、有严密论证的书籍（如《高效能人士的七个习惯》）。
	* 关键练习：阅读后，先尝试自己提炼大纲，再与AI生成的总结进行比对，观察AI是如何将内容结构化的。
2. 通过“写作”固化思维链条
	* 为什么：能说未必能写。写作能暴露思维的不连贯，是锻炼逻辑严谨性和执行力的关键。
	* 怎么做：采用“结构化写作法”，而非从头到尾硬写。
		* 步骤：先列总论点 → 再拆解分论点 → 最后填充内容。如同先建骨架，再添血肉。
	* 实践与辅助：
		* 从写工作周报等日常任务开始练习。
		* 利用AI作为“教练”：将自己写的初稿交给AI扩写，或向AI口述思路让其整理成大纲，对比学习AI的结构化方式。

### 三、 核心工具：批判性思维模型——ORACLE

这是分析和审视任何论述（包括自己想法）的六步心法。其核心是区分观点与事实，并审视论证过程。

1. O: Objective/Purpose (目标/观点)
	* 行动：首先识别对方的核心观点或目的。
	* 关键：严格区分观点与事实。
	* 例子：“夏老师是人”是事实；“夏老师是好人”是观点（“好”需要论证）。
2. R: Reason (理由)
	* 行动：找出支持该观点的理由、论据。
	* 例子：观点是“人要有稳定的价值观”，理由是“能排除干扰、成为长期主义者”。
3. A: Assumption (假设)
	* 行动：找出连接“观点”和“理由”的未言明的隐藏前提。这是批判性思维的关键一跃。
	* 例子：
		* “要996，因为能提高效率” → 隐藏假设是“996 = 高效率”。
		* “夏老师是好人，因为他常帮助别人” → 隐藏假设是“帮助别人的人 = 好人”。这个假设可能不成立（如帮助了坏人）。
4. C: Counter-argument (反证/限制条件)
	* 行动：找出使上述假设不成立的反例或限制条件。不是为了抬杠，而是为了审视论证的边界。
	* 例子：对“996=高效率”这个假设，可以思考：在什么条件下（如目标清晰、激励到位）才可能成立？当前条件具备吗？
5. L: Logic (逻辑谬误)
	* 行动：检查论证过程中是否存在常见的逻辑错误。
	* 常见谬误与例子：
		* 因果谬误：“因为上个月加班后绩效好，所以这个月加班也能绩效好”（将时间先后误认为因果）。
		* 错误类比：将上个月的市场环境简单套用到本月。
		* 非黑即白：认为“领导不好”是“工作辛苦”的唯一原因。
6. E: Effect (影响)
	* 行动：全面评估该观点若实施，可能带来的正面与负面的后续影响。
	* 例子：推行“996”除了可能提升效率，还会带来员工士气低落、合规风险、成本增加等潜在影响。

### 四、 如何整合运用？

将 ORACLE模型 作为脚手架，应用于你的阅读和写作中：

* 阅读时：不只是吸收信息，而是用ORACLE模型去拆解文章的论点、审视其论证。
* 写作/思考时：用ORACLE模型来构建和检验自己的论述是否严谨。

最终，逻辑能力的提升是一个循环：通过“读写”积累素材和结构感，通过“ORACLE”模型提升思考的深度和锐度，两者结合，持续练习，才能内化为强大的逻辑思维能力。 正如作者所言，其持续每年阅读百本书的实践，正是这种方法论的基础。
