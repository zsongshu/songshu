# 数据库研发中心述职-2023年度述职安排

1. 一、背景及要求
	

1. 述职在美团实践多年，是一种团队集体总结工作、反思自我、互相反馈，从而实现共同学习成长的机制。对于管理者而言，组织团队述职是管理基本功中“管团队”的重要内容，也是“管一层，看两层”的具体实践场景。
2. 围绕管理主干，踩好公司关键管理动作节奏，基于24年OP，思考组织及人才策略，为人才盘点和年度激励提供信息输入。
3. 考虑到各团队面临的稳定性风险及业务压力情况不同，本次年度述职对述职人员的范围不做统一要求，各团队述职安排由管理者决策，对于不组织述职的团队，需通过讨论会、共创会、或1on1等形式，对23年工作做回顾，对24年规划进行讨论。
4. 述职中请参考公司统一的人才指引[美团领导力原则](https://km.sankuai.com/page/1339186875)进行准备和相互反馈。

#### 二、述职安排

**1.** **述职人员**

* 管理班子专场述职
* DBA小组长专场述职
* 校招生专场述职

**2.** **述职时间**
2024年1月2日\-2024年2月2日
**3.** **述职流程**
员工述职建议不超过40min/人，管理者述职建议不超过60min/人。

|     |     |     |     |
| --- | --- | --- | --- |
| **序号** | **环节** | **内容** | **时长** |
| 1   | 阅读述职材料 | 参会人员阅读述职同学的材料 | 5-10min |
| 2   | 四问四答 | 述职者回答：最满意的事、最遗憾的事、最委屈的事、最大的认知提升是什么 | 5min |
| 3   | 提问与反馈 | 1）参加述职的同学对述职者轮流提问，每个问答不超过5分钟<br>2）反馈者给予激励性反馈及建设性反馈，部门负责人最后反馈 | 20-40min |
| 4   | 个人总结 | 述职者简单总结，表达感想、收获、行动计划等 | 5min |
