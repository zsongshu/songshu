# 外卖交易链路



|     |     |
| --- | --- |
| 提单数 | 只要用户在订单页面提交了订单，就会有一条提单记录；不管这个订单后续是否支付成功，是否货到付款，是否被取消等等都不会对提单数造成影响；提单数是所有用户有过下单行为的提单记录的总和。 |
| 推单数 | 在线支付用户提交了订单，并且支付成功后，此订单才会被推送给商家，称为推单数（如果用户在支付过程中就取消了订单或者根本没有支付成功，或者支付成功后被系统取消了订单等情况，此订单就不会推送给商家，商家也不会看见这些订单；货到付款用户提交订单之后，订单会立即推送给商家；订单只有在推送给商家之后，才能进入后续的流转过程，此为推单）。 |
| 提单数与推单数的关系 | 推单数=提单数-在线30分钟未支付系统自动取消订单数-顾客在线支付过程中主动取消订单数-不符合首购资格系统自动取消订单数-账户优惠异常系统自动取消订单数。 |
| 订单数 | 指的是有效订单数，即所有交易成功的订单数的总和；如果一个订单最后被取消了，不管是何种原因何种情况被取消的，都不会算在订单数（即有效订单数）之内； |
| 提单数、推单数和订单数的关系 | 提单数、推单数、订单数的大小关系是：提单数＞推单数＞订单数； <br>提单数、推单数、订单数在时间上的关联是： 一个订单提交 →  成为提单数 → 用户支付成功，订单又没有被取消 → 推送给商家 → 成为推单数 → 这个订单最后交易成功，并没有被取消 → 成为订单数； |
| GMV和GTV | GMV只统计完成订单、不包含已取消订单，而GTV包含所有支付了的订单，包括退款的订单 |
