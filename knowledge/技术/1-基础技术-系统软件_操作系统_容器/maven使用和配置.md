# maven使用和配置

|     |     |
| --- | --- |
| maven-compiler-plugin | 编译Java源代码 |
| maven-surefire-plugin | 是 Maven 的一个单元测试插件，用于执行项目的单元测试。<br>在 <configuration> 标签中，定义了 <argLine> 参数，这个参数用于指定在启动 JVM 时的参数。 |
| jacoco-maven-plugin | 用于在Maven构建过程中执行代码覆盖率分析。<br><br>* <executions>标签下定义了两个<execution>，分别是pre-unit-test和post-unit-test。<br>* pre-unit-test的目标是prepare-agent，在单元测试前准备JaCoCo代理。<destFile>定义了覆盖率报告的输出路径。<br>* post-unit-test在test阶段执行，目标是report，生成覆盖率报告。<dataFile>定义了覆盖率数据文件的路径，<outputDirectory>定义了覆盖率报告的输出目录。 |
| build-helper-maven-plugin | 插件提供了一些额外的功能来帮助我们构建项目。<br><br>* <groupId>、<artifactId>、<version> 这三个元素定义了插件的坐标，用于 Maven 在仓库中查找插件。<br>* <executions> 元素包含了一个或多个 <execution> 元素，每个 <execution> 元素定义了插件的一个执行阶段。<br>* 在 <execution> 元素中，<id> 元素定义了执行阶段的唯一标识符，<phase> 元素定义了执行阶段在 Maven 生命周期中的哪个阶段执行，这里是 generate-test-sources 阶段。<br>* <goals> 元素包含了一个或多个 <goal> 元素，每个 <goal> 元素定义了插件的一个目标，这里是 add-test-source 目标。<br>* <configuration> 元素用于配置插件的参数，这里配置了 sources 参数，指定了额外的测试源代码目录 src/test/evosuite。<br><br>总的来说，这段代码的作用是在 Maven 的 generate-test-sources 阶段，添加额外的测试源代码目录 src/test/evosuite。<br><br> |
| maven-assembly-plugin | 插件主要用于项目打包，可以将项目的编译、测试、运行等所有需要的依赖和资源打包到一个可执行的 jar 包中。<br><br><br><br>* <configuration>：插件的配置信息。<br>	* <descriptors>：定义了 assembly 描述符的位置，描述符文件用于指定打包时的一些规则，如包含哪些文件，排除哪些文件等。<br>	* <archive>：定义了生成的 jar 文件的 manifest 文件的内容。<mainClass> 指定了应用的入口类，即包含 main 方法的类。<br>* <executions>：定义了插件的执行阶段和目标。<br>	* <execution>：一个执行阶段的配置。<br>		* <phase>：定义了插件执行的阶段，这里是 package 阶段，即打包阶段。<br>		* <goals>：定义了插件的目标，这里是 single，表示只生成一个包含所有依赖和资源的 jar 文件。 |
