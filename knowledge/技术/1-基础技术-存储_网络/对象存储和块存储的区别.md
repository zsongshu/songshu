# 对象存储和块存储的区别

数据单元不同：对象存储将文件作为一个整体存储，以“对象”（Object）的形式存储。每个对象都有一个唯一的标识符，可以通过标识符访问。而块存储将文件分成块，每个块都有一个唯一的标识符。

存储方式不同：对象存储将文件存储为一个整体，直接存储在云存储系统中。而块存储将文件分成块，每个块独立存储在不同的地方，需要通过一个映射表来确定每个块的位置。

访问方式不同：对象存储是通过 API 接口来访问的，可以通过 HTTP 或者 RESTful 接口进行操作。块存储则是通过一个协议来访问，例如 iSCSI。

适用场景不同：对象存储适用于需要频繁访问的大量数据，例如图片、视频、音频等富媒体文件。而块存储适用于需要频繁访问和更改的数据，例如数据库、虚拟机等应用。
