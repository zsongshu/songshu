|     |     |     |
| --- | --- | --- |
|  | **bbr** | **cubic** |
| 机制  | 基于发送速率；通过估计网络带宽（BtlBw）和往返时间（RTprop）来调整发送速率； | 基于窗口；通过更平滑的方式调整窗口大小，以提高性能和稳定性； |
| 适应性 | 处理高延迟和高带宽的网络环境时表现出色；基于延迟的探测机制，能够更好地适应网络变化，减少丢包和延迟； | 在传统网络环境中表现良好，尤其在丢包率较低且网络缓冲区较小的情况；能够高效地利用带宽； |
| 性能  | 在高延迟和高带宽的网络环境中能够显著降低延迟并提高吞吐量； | 通过更平滑的窗口调整机制，提高了网络的稳定性和吞吐量。它在避免网络拥塞的同时，能够高效地利用网络资源； |
| 实际效果 | 在需要高吞吐量和低延迟的场景中表现出色； | 是Linux内核默认的拥塞控制算法之一，在处理常规的网络流量时表现出良好的性能和稳定性 |
