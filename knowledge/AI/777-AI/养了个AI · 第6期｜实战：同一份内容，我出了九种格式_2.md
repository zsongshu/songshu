# **01 "格式"这件事，我们都想错了**

先说一个常见的误区。

很多人用AI的方式是这样的：

* 需要PPT → 让AI出PPT
* 需要报告 → 让AI写报告
* 需要图片 → 让AI生成图片

每次都是从零开始，每次都重新描述需求，每次都在说"这个报告是关于……"

效率低，不说。关键是：你养出来的AI，什么都没学会。

这期我想演示一种不一样的工作方式——

准备一份内容底料，让AI把它翻译成九种语言。

九种"语言"，指的是九种交付格式：

PPT幻灯片、KIM文档报告、Excel数据表、AI生成概念图、信息图、知识漫画、商务风网页、清爽调研风网页、塞尔达冒险风网页。

九种格式，内容只有一份，准备一次。

# **02 内容底料：2026年AI产品全景报告**

为了让这次演示有意义，我选了一个我最近研究比较深的主题：

「2026年AI产品格局，究竟变成什么样了？」

这不是随机选的话题。过去几个月，我帮AI（我给我的AI助手取名"林克"）积累了大量AI行业的知识——每天跑日报、每周出周报、不断往知识库里塞新材料。

所以当我需要一份"底料"的时候，林克可以直接从记忆里调取，不用重新搜索。

这是养了AI的好处：它的知识是真的在积累，不是每次对话都清零。

底料的核心内容：

2026年AI产品格局已从"百花齐放"走向"两极分化"：通用助手被巨头垄断，垂直工具在专业场景反超，中美两个市场完全独立运行。

七大赛道：对话助手、AI编程、图像生成、视频生成、AI搜索、AI语音、企业平台

三大趋势：超级App vs 垂直工具 · AI原生 vs AI增强 · 中美市场分治

三个反常识判断：通用 ≠ 制胜 · 中国 ≠ 落后 · 大公司 ≠ 必赢

有了这份底料，我让林克同时出九种格式。下面是过程实录。

## **4.2 信息图**

调用方式：ks-design-infographic 技能

说的话："用bento-grid布局 + corporate-memphis风格，生成一张2026年AI产品全景信息图，横向16:9，包含七大赛道、资本数据、三大趋势，所有文字中文。"

结果：

AI生成的高密度信息图，bento-grid布局，扁平矢量风格，核心数据可视化。

![a14bb61e957bf1a0b5d0f0ab018b75d2.jpeg](https://h4.static.yximgs.com/udata/pkg/EE-KSTACK/a14bb61e957bf1a0b5d0f0ab018b75d2.jpeg)

信息图和AI生图的区别在哪里？

* **AI生图**：感性，传递情绪和氛围，让人记住"这个领域的感觉"
* **信息图**：理性，传递结构和数据，让人理解"这个领域的逻辑"

同一份内容，两种视觉语言，互相补充。

"以为大公司稳赢 → 小团队4年就追上来了"——这个情节，漫画比表格更有感染力。

# **05 网页部署组：三种风格网页**

这是这期里面最有意思的一组。

为什么要出三种风格的网页？

不是为了炫技。是因为不同的使用场景，需要不同的信息密度和视觉语言：

|     |     |     |
| --- | --- | --- |
| **场景** | **风格** | **核心诉求** |
| 发给老板/汇报用 | 商务风 | 专业、克制、数据可信 |
| 发给同事/调研用 | 清爽调研风 | 清晰、可导航、方便扫读 |
| 发给自己/沉浸阅读 | 冒险游戏风 | 有趣、沉浸、让人想读完 |

同一份数据，面向不同受众，选不同的"包装"。

格式不是内容的附属品，是内容的传播载体。选对载体，内容才能到达对的受众。
