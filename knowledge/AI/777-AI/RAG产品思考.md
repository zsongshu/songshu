# RAG产品思考

![[RAG产品思考-933ae333.docx]]

## 内容

+-------------------------------------+-----------------------------------------------------------------+
| 结合检索和生成，提升LLM输出的准确性 | 解决胡说八道的问题                                              |
+-------------------------------------+-----------------------------------------------------------------+
| RAG VS 模型微调                     | - 微调理论上可以为模型永久的注入领域知识                        |
|                                     |                                                                 |
|                                     | - 成本和实时性，RAG优势大                                       |
+-------------------------------------+-----------------------------------------------------------------+
| RAG VS 长上下文                     | - 长上下文                                                      |
|                                     |                                                                 |
|                                     |   - 随着上下文长度增加，准确度不断降低                          |
|                                     |                                                                 |
|                                     |   - 距离越远的信息越容易遗漏                                    |
|                                     |                                                                 |
|                                     |   - 增加成本和延迟                                              |
|                                     |                                                                 |
|                                     | - RAG检索快，成本低                                             |
+-------------------------------------+-----------------------------------------------------------------+
| RAG处理流程                         | - 上传链路                                                      |
|                                     |                                                                 |
|                                     |   - 1、文本切块：把Document拆分成Chunks                         |
|                                     |                                                                 |
|                                     |   - 2、向量化并保存：把Chunk进行Embedding，存入VectorDB         |
|                                     |                                                                 |
|                                     |   - 本质是把原始信息转化成一个浓缩了关键信息的向量              |
|                                     |                                                                 |
|                                     | - 检索链路                                                      |
|                                     |                                                                 |
|                                     |   - 1. 召回，通过用户的query的关键字和Embedding，检索出相关文档 |
|                                     |                                                                 |
|                                     |   - 2、借助 RRF算法粗排，过滤掉相似度低的文档                   |
|                                     |                                                                 |
|                                     |   - 3、使用重排模型进行精排，返回用户所需的Top-k文档            |
|                                     |                                                                 |
|                                     |   - 本质是通过向量相似度计算，定位到最匹配的信息                |
+-------------------------------------+-----------------------------------------------------------------+
| 评测指标                            | - 检索质量                                                      |
|                                     |                                                                 |
|                                     |   - 召回率                                                      |
|                                     |                                                                 |
|                                     |     - 检索系统返回相关文档占全部相关文档的比例，"查得全"的能力  |
|                                     |                                                                 |
|                                     |   - 准确率                                                      |
|                                     |                                                                 |
|                                     |     - 返回结果中相关文档的比例，"查得准"的能力                  |
|                                     |                                                                 |
|                                     | - 生成质量                                                      |
|                                     |                                                                 |
|                                     |   - 忠实度                                                      |
|                                     |                                                                 |
|                                     |     - 生成的答案与给定上下文之间的事实一致性                    |
|                                     |                                                                 |
|                                     |   - 相关性                                                      |
|                                     |                                                                 |
|                                     |     - 答案与用户问题之间相关程度                                |
|                                     |                                                                 |
|                                     | - 业务                                                          |
|                                     |                                                                 |
|                                     |   - 最终回答准确率/满意度等                                     |
|                                     |                                                                 |
|                                     |     - 需要结合用户场景才能获取，类似Prompt评测 & 微调模型评测   |
