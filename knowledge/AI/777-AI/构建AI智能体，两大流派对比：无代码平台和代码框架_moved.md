# 构建AI智能体，两大流派对比：无代码平台和代码框架



|     |     |     |
| --- | --- | --- |
|  | 低代码 | 代码  |
| 典型代表 | 扣子、Dify | [Langchain](https://zhida.zhihu.com/search?content_id=727703391&content_type=Answer&match_order=1&q=Langchain&zhida_source=entity) |
| 优势  | * **门槛极低：** 不需要你会写代码，点点鼠标，拖拖拽拽，配置一下，就能快速搭建一个AI智能体。对产品经理、运营或者想快速验证想法的个人开发者非常友好。<br>* **上手快，出活快：** 对于一些逻辑相对简单、需求明确的场景，比如做一个能回答特定领域知识的客服机器人，用无代码平台效率非常高。<br>* **集成度高：** 通常会内置很多常用的API、插件和服务，省去了自己去对接的麻烦。 | * **高度灵活性和可定制性：** 这是最大的优点。你可以像搭积木一样，自由组合不同的模块（大语言模型、向量数据库、记忆模块、工具调用等），实现非常复杂的逻辑和功能。想怎么调校，就怎么调校。<br>* **掌控力强：** 从数据处理、模型选择、提示工程到业务逻辑，每一个环节你都可以深入介入和优化。知其然，更知其所以然。<br>* **生态丰富：** 尤其是Python生态，拥有海量的AI/ML库（如TensorFlow, PyTorch, Transformers, scikit-learn）、数据处理工具（Pandas, NumPy）和社区支持。遇到问题，很容易找到解决方案。<br>* **开源为主：** 很多优秀的框架都是开源的，这意味着你可以免费使用，甚至参与贡献，不用担心被“卡脖子”。<br>* **可移植性与可扩展性：** 基于代码的实现更容易部署到不同的环境，也更容易随着业务发展进行扩展。 |
| 劣势  | * **灵活性的天花板：** “成也萧何败萧何”，低门槛往往也意味着自由度的受限。当你的需求稍微复杂一点，想要精细化控制AI的行为、逻辑流转，或者引入一些特别定制化的功能时，无代码平台可能就显得力不从心了。<br>* **“黑箱”感：** 底层很多东西是封装好的，你很难深入了解和修改其核心机制。对于追求极致性能和深度定制的开发者来说，这可能是个硬伤。<br>* **平台依赖：** 你构建的智能体强依赖于平台，迁移成本高，万一平台政策调整或者停止服务，就比较被动了。 | * **门槛较高：** 需要具备编程能力，特别是Python编程能力。对于没有编程基础的同学来说，上手曲线会比较陡峭。<br>* **开发周期相对较长：** 相比无代码平台的“立竿见影”，用代码从零开始构建或者基于框架进行深度开发，需要投入更多的时间和精力。<br>* **“轮子”的选择与维护：** 框架和库的选择很多，有时也会面临“选择困难症”，并且需要自己处理版本兼容、依赖管理等问题。 |
