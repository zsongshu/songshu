+-------------------------------------------------------------------------------------------------------------+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| 概览                                                                                                        | ![](media/af219128fa673543454b00b43632d9b4.png){width="6.958333333333333in" height="4.041666666666667in"}                                                                                                                                                                                                                                                                                                        |
|                                                                                                             |                                                                                                                                                                                                                                                                                                                                                                                                                  |
|                                                                                                             | **MCP 的传输机制（Transport）指的是客户端与服务端之间的通信机制。**需遵循以下原则：                                                                                                                                                                                                                                                                                                                              |
|                                                                                                             |                                                                                                                                                                                                                                                                                                                                                                                                                  |
|                                                                                                             | - **消息格式**：所有 MCP 消息都必须是 [[JSON-RPC]{.underline}](https://zhida.zhihu.com/search?content_id=260842739&content_type=Article&match_order=1&q=JSON-RPC&zhida_source=entity) 格式，UTF-8 编码。                                                                                                                                                                                                         |
|                                                                                                             |                                                                                                                                                                                                                                                                                                                                                                                                                  |
|                                                                                                             | - **两种标准化的传输方式**：stdio (标准输入/输出)、[[Streamable HTTP]{.underline}](https://zhida.zhihu.com/search?content_id=260842739&content_type=Article&match_order=1&q=Streamable+HTTP&zhida_source=entity) 。在可能的情况下，客户端应当支持标准输入输出 (stdio)。                                                                                                                                          |
|                                                                                                             |                                                                                                                                                                                                                                                                                                                                                                                                                  |
|                                                                                                             | - 客户端和服务器可以通过模块化的方式实现自定义的传输机制。                                                                                                                                                                                                                                                                                                                                                       |
+-------------------------------------------------------------------------------------------------------------+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| 传输协议                                                                                                    | 1.  stdio：客户端直接启动并管理服务进程，默认环境隔离，支持会话持久化                                                                                                                                                                                                                                                                                                                                            |
|                                                                                                             |                                                                                                                                                                                                                                                                                                                                                                                                                  |
|                                                                                                             | ![](media/441f3028634d89bfb6ac6a50e632ebdb.jpeg){width="7.46875in" height="6.708333333333333in"}                                                                                                                                                                                                                                                                                                                 |
|                                                                                                             |                                                                                                                                                                                                                                                                                                                                                                                                                  |
|                                                                                                             | 2.  **HTTP+SSE**： 客户端通过 HTTP POST 发送请求，服务器通过一个单独的 SSE ([[Server-Sent Events]{.underline}](https://zhida.zhihu.com/search?content_id=260842739&content_type=Article&match_order=1&q=Server-Sent+Events&zhida_source=entity)) 端点推送响应，在客户端与服务器之间建立一条持久化连接。                                                                                                          |
|                                                                                                             |                                                                                                                                                                                                                                                                                                                                                                                                                  |
|                                                                                                             |     - **连接的维护成本高**：需要维护两个独立的连接/端点（endpoint）。                                                                                                                                                                                                                                                                                                                                            |
|                                                                                                             |                                                                                                                                                                                                                                                                                                                                                                                                                  |
|                                                                                                             |     - **资源消耗高**：必须保持长连接，在高并发情况下可能导致显著的资源消耗。长连接也使得无状态实现变得困难。                                                                                                                                                                                                                                                                                                     |
|                                                                                                             |                                                                                                                                                                                                                                                                                                                                                                                                                  |
|                                                                                                             |     - **基础设施兼容性差**：许多现有网络基础设施可能无法正确处理长期的 SSE 连接。企业防火墙可能会强制终止超时的连接，使得服务变得不可靠。                                                                                                                                                                                                                                                                        |
|                                                                                                             |                                                                                                                                                                                                                                                                                                                                                                                                                  |
|                                                                                                             |     - **连接的可恢复性差**：在网络问题的情况下缺乏连接的可恢复性。这给需要通过互联网访问、可能面临连接中断的远程 MCP 服务器带来了挑战。                                                                                                                                                                                                                                                                          |
|                                                                                                             |                                                                                                                                                                                                                                                                                                                                                                                                                  |
|                                                                                                             | 3.  **Streamable HTTP**： 服务端使用单一的 HTTP 端点统一处理请求和响应，服务器根据需要选择返回标准 HTTP 响应或启用 SSE 流。                                                                                                                                                                                                                                                                                      |
|                                                                                                             |                                                                                                                                                                                                                                                                                                                                                                                                                  |
|                                                                                                             | ![](media/63751009c7eaa164ddc48cb0bf83de3b.webp){width="7.3125in" height="2.8020833333333335in"}                                                                                                                                                                                                                                                                                                                 |
|                                                                                                             |                                                                                                                                                                                                                                                                                                                                                                                                                  |
|                                                                                                             | - **简化的架构**：减少了客户端和服务器之间的连接数量，降低了系统复杂性。                                                                                                                                                                                                                                                                                                                                         |
|                                                                                                             |                                                                                                                                                                                                                                                                                                                                                                                                                  |
|                                                                                                             | - **更低的资源消耗**：单一连接管理更高效，减少了服务器资源使用。                                                                                                                                                                                                                                                                                                                                                 |
|                                                                                                             |                                                                                                                                                                                                                                                                                                                                                                                                                  |
|                                                                                                             | - **改进的兼容性**：更好地适应现有的网络基础设施，减少了与防火墙和代理服务器的兼容性问题。                                                                                                                                                                                                                                                                                                                       |
|                                                                                                             |                                                                                                                                                                                                                                                                                                                                                                                                                  |
|                                                                                                             | - **按需流式传输**：对于简单的请求，可以返回直接的 HTTP 响应，无需建立长连接。                                                                                                                                                                                                                                                                                                                                   |
|                                                                                                             |                                                                                                                                                                                                                                                                                                                                                                                                                  |
|                                                                                                             | - **智能降级**：在网络条件不佳时，可以自动降级到标准的 HTTP 模式。                                                                                                                                                                                                                                                                                                                                               |
|                                                                                                             |                                                                                                                                                                                                                                                                                                                                                                                                                  |
|                                                                                                             | - **资源优化**：根据请求的复杂性动态分配服务器资源，以提高整体效率。                                                                                                                                                                                                                                                                                                                                             |
|                                                                                                             |                                                                                                                                                                                                                                                                                                                                                                                                                  |
|                                                                                                             | - **会话一致性**：通过[[ Mcp-Session-Id]{.underline}](https://zhida.zhihu.com/search?content_id=260842739&content_type=Article&match_order=1&q=+Mcp-Session-Id&zhida_source=entity) 头确保跨请求的状态一致性。                                                                                                                                                                                                   |
|                                                                                                             |                                                                                                                                                                                                                                                                                                                                                                                                                  |
|                                                                                                             | - **断线重连**：支持 [[Last-Event-ID]{.underline}](https://zhida.zhihu.com/search?content_id=260842739&content_type=Article&match_order=1&q=Last-Event-ID&zhida_source=entity) 机制，确保断线后未收到的消息可以被恢复。                                                                                                                                                                                          |
|                                                                                                             |                                                                                                                                                                                                                                                                                                                                                                                                                  |
|                                                                                                             | - **状态恢复**：允许客户端在重新连接时恢复之前的会话状态，提升用户体验。                                                                                                                                                                                                                                                                                                                                         |
