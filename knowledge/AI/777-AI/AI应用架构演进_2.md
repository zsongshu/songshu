# AI应用架构演进

### 从 CNN 到 GPT：AI 架构演进全景图

|     |     |     |     |     |
| --- | --- | --- | --- | --- |
| **架构名称** | **核心功能** | **主要应用场景** | **实现原理简述** | **缺点** |
| **CNN** (卷积神经网络) | **空间特征提取** | 图像识别、目标检测、医疗影像。 | CNN 根据局部特征比对目标与参照物是否一致 | CNN只看局部，无法识别眼睛长在屁股上的问题 |
| **RNN** (循环神经网络) | **时间序列建模** | 语音识别、股票预测、基础翻译。 | RNN 根据历史上下文来预测下一个字/词 | RNN 不能并行 |
| **Transformer** | **全局关系建模** | 机器翻译、多模态基础、大模型底座。 | Transformer 通过“自注意力机制”构建全局关联矩阵，通过计算 Token 之间的语义相似度（血缘关系）来理解信息 | Transformer的N\*N 的矩阵，上下文增加，意味着计算量平方级增加 |
| **BERT** (Encoder-only) | **双向语义理解** | 语义搜索、情感分析、NER。 | 采用 Transformer 的 **Encoder** 部分。利用 **Masked LM (掩码语言模型)** 学习上下文的双向关系。 | 擅长“理解”不擅长“生成”。通过海量数据预处理，极大提升了 NLP 下游任务的效果。 |
| **GPT** (Decoder-only) | **文本生成与推理** | 聊天机器人、内容创作、Agent 驱动。 | 采用 Transformer 的 **Decoder** 部分。通过 **Autoregressive (自回归)** 预训练，预测下一个 Token。 | 坚持“大力出奇迹”。从 GPT-3 开始展现出 **In-context Learning** 能力，是目前 AGI 的主流路径。 |
